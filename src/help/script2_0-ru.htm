Скрипт 2.0

В 2026 году в рамках масштабного обновления системы SalixEDA была разработан и внедрен обновленный набор скриптовых функций создания 3d моделей. Основной целью обновления было упрощение использования скриптов для конечного пользователя.

3d модели описываются на скриптовом языке, похожим на язык программирования. Все действия по построению выполняются функциями, а сами объекты могут храниться в переменных. Ниже представлен типичный код построения выводного конденсатора.

#First place source params of part bodyDiametr = 6 bodyHeight = 10 bodyColor = selectColor( "#008080" ) #Second place source params of pins pinDiametr = 0.8 pinLength = 3 pinDistance = 2.5 pinColor = selectColor( "#c0c0c0" ) #======================================================== #Body construction body = solidCylinder( bodyDiametr / 2, bodyHeight, true ) #Place model into destignation model. After this you can see your construction partModel = modelSolid( bodyColor, body, 0,0,0, 0,0,0 ) #========================================================= #Pin construction pin = solidCylinder( pinDiametr / 2, -pinLength, false ) #First pin placement pinModel = modelSolid( pinColor, pin, 0,0,0, -pinDistance / 2,0,0 ) #Second pin placement pinModel = modelSolidCopy( pinModel, 0,0,0, pinDistance / 2,0,0 ) #Place pin model into destignation model partModel = pinModel

Трехмерная модель состоит из трехмерных тел. В модели может присутствовать несколько копий одного и того-же тела, например выводы компонентов. В любом случае для каждого тела и копии задается местоположение и ориентация.

Тело строится набором простых форм (цилиндр, параллелепипед и т.п.). Эти простые формы устанавливаются друг на друга. Первая простая форма задается одной из функций solidXXX. Последующие простые формы добавляются на эту форму с помощью функций solidAddXXX. Для добавляемых простых форм можно также поменять цвет.

Из тела формируется модель путем указания ее начального цвета (цвет может поменяться в добавляемых формах), ориентации и положения. Это делается с помощью функции modelSolid.

При необходимости может быть сформирована копия модели. Это делается с помощью функции modelSolidCopy. В этой функции задается ориентация и положение новой копии.

Все простые тела строятся по центру координат. Дополнительно тело может строиться с помощью универсальной функции solidNew, в которую передается двумерная проекция тела и его высота. Двумерные проекции также используются в функциях добавления solidAddDifXXX, когда форма добавляемого тела не совпадает с формой предыдущего.

Для создания двумерных форм (проекций) служат функции flatXXX. Например, функция flatRectangle( float width, float height ) создает прямоугольник с указанными размерами. Все фигуры создаются по центру координат. Это означает, что геометрический центр фигуры будет в точке 0,0. Это можно поменять с помощью функции flatOffset( float offx, float offy ). Эта функция смещает геометрический центр фигуры в заданную точку.

Функции solidXXX служат для создания трехмерных фигур. В арсенале таких фигур параллелепипед, цилиндр, труба, чашка.

Функции solidAddXXX служат для добавления на верхнюю грань трехмерного выступа или ниши. Есть варианты функций, которые повторяют форму верхней грани фигуры, а есть которые добавляют произвольные формы.
