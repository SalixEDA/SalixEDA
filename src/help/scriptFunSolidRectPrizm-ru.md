# solidRectPrizm

## Формат вызова
`faceList solidRectPrizm( float lenght, float width, floatList floors[lenght, width, offx, offy, height...], bool addBottom )`

## Описание
Строит призму с прямоугольным основанием и несколькими этажами тоже прямоугольного
профиля. Размеры и положение каждого этажа можно изменять, что позволяет строить,
например, катушки трансформаторов или корпус микросхемы.

## Параметры
- lenght - длина основания
- width - ширина основания
- floors - массив чисел, где каждая пятерка чисел описывает один этаж
- addBottom - когда true добавляется нижняя грань, в противном случае - не добавляется

### Описание этажа
- lenght - длина прямоугольника этажа
- width - ширина прямоугольника этажа
- offx - смещение центра этажа по оси X
- offy - смещение центра этажа по оси Y
- height - высота этажа

## Пример использования

```
body = solidRectPrizm( 4, 2, [ 4.4, 2.4, 0, 0, 0.5,
                               4,   2,   0,  0, 0.5], true )

partModel = modelSolid( selectColor("#800000"), body, 0,0,0, 0,0,0 )
```
