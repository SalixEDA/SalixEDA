- Формирование файлов производства
-- Файлы для производства формируются из графического редактора плат.
-- Чтобы сформировать файлы для производства выбираем пункт меню Файл|Экспорт
-- В списке "Тип мастера" выбираем Экспорт в Gerber-файл.
-- Gerber-файлы лучше формировать пакетно. Так быстрее. Воспользуемся для этого правой
стороной диалога.
-- Выбираем директорий, где будут расположены сформированные Gerber-файлы.
-- Отмечаем в таблице какие файлы нужно сформировать.
-- Нажимаем кнопку, чтобы запустить процесс генерации.
-- Система последовательно формирует требуемые файлы.
-- Завершаем диалог.
-- Для формирования файла установщика компонентов выбираем пункт меню Файл|Экспорт
-- В списке "Тип мастера" выбираем "Для установщика STM".
-- Оставляем все поля по умолчанию. Это приведет к формированию файла для установщика
компонентов с верхней стороны. Нажимаем на кнопку для формирования файла.
