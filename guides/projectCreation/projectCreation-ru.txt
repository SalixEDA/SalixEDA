- Создание нового проекта и схемы в нем
-- Для создания нового проекта нужно нажать на эту кнопку.
-- При этом создается пустой проект и в левой части показывается дерево проекта.
-- Для создания листа схемы или любого другого объекта проекта нужно нажать
на эту кнопку.
-- Появляется диалоговое окно создания объекта проекта.
-- В списке типов объекта этого диалога нужно выбрать "Схема".
-- Появляется список возможных способов создания схем.
-- В качестве способа создания выбираем "Мастер схем".
-- Нажимаем Далее для перехода к выбору мастера схем.
-- Так как в качестве способа создания был выбран "Мастер схем", то на следующем
шаге появляется диалог с выбором доступного мастера создания схем. Выбираем в нем
мастер "Оформление схем".
-- И нажимаем Далее для перехода к выбору оформления.
-- Появляется диалоговое окно со списком доступных коллекций оформления.
-- В списке найденных коллекций оформления выбираем "form iso".
-- В списке секций выбираем вариант "iso a4" как основу оформления.
-- Нажимаем ОК для вставки оформления в схему.
-- Появляется запрос имени для создаваемого объекта. В данном случае листа схемы.
Имя листа схемы можно оставить по умолчанию, но для символов, корпусов и компонентов
задавайте реальные имена.
-- Для создания схемы нажимаем кнопку "Завершить".
