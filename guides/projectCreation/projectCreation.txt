- Создание нового проекта и схемы
-- Нажмите кнопку Новый проект в панели инструментов
-- Нажмите кнопку Новый объект в панели инструментов
-- Выберите в списке Схема
-- Среди возможных вариантов создания выберите Пустая
-- Нажмите Далее и введите имя для новой схемы
-- Нажмите Завершить для создания

- Рисование линии
-- Нажмите кнопку Линия в панели инструментов
-- В списке доступных слоев выберите слой для линии
-- Укажите первую точку линии
-- Укажите вторую точку линии
-- Линия вводится как ломаная. Чтобы прекратить ввод - нажмите правую кнопку
