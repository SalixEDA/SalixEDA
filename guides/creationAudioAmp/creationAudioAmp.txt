- Введение
-- Будем создавать простой аудио-усилитель
-- Нарисуем схему
-- Разведем плату

- Создание проекта
-- Нажимаем кнопку создания нового проекта
-- Нажимаем кнопку создания объекта проекта
-- Выбираем схему, мастера схем и Далее
-- Выбираем мастер форматов
-- Выбираем формы iso
-- В списке секций выбираем iso a4 first
-- Нажимаем кнопку ОК
-- Нажимаем кнопку Завершить
-- Открывается созданная схема для редактирования

- Создание схемы-компоненты
-- Нажимаем кнопку выбора компонентов из библиотеки.
-- В поле поиска вводим часть названия компонента.
-- И нажимаем Enter или кнопку Искать.
-- В списке поиска отмечаем нужный компонент.
-- Нажимаем ОК.
-- Размещаем компонент на схеме.
-- Нажимаем правую кнопку мыши для выбора следующего компонента.
-- Вводим название следующего компонента.
-- Нажимаем Поиск.
-- Вставляем в схему.
-- Можно вставить несколько экземпляров сразу.
-- Изменим ориентацию компонента.
-- Вставляем компонент.
-- Вставляем третий экземпляр компонента.
-- Нажимаем правую кнопку мыши.
-- Вводим часть названия для поиска следующего компонента.
-- Нажимаем Поиск.
-- Выбираем компонент из списка найденных.
-- Меняем ориентацию.
-- Вставляем в схему.
-- Нажимаем правую кнопку мыши.
-- Меняем номинал для поиска следующего компонента.
-- Нажимаем Поиск.
-- Выбираем из списка найденных.
-- Вставляем в схему.
-- Нажимаем правую кнопку мыши.
-- Вводим название разъема.
-- Нажимаем Поиск.
-- Выбираем разъем из списка.
-- У разъема меняем зеркальность, чтобы он смотрел в другую сторону.
-- Вставляем в схему.
-- Нажимаем правую кнопку мыши.
-- Меняем название разъема.
-- Нажимаем Поиск.
-- Выбираем из списка.
-- Меняем зеркальность.
-- Вставляем в схему.
-- Нажимаем правую кнопку мыши.
-- Вводим название заключительного компонента.
-- Нажимаем Поиск.
-- Выбираем из списка нужный нам компонент.
-- Вставляем в схему.

-- Перемещая мышь подбираем нужный нам вариант.
-- Нажимаем среднюю кнопку, чтобы согласиться с разумным режимом.
-- Перемещаем мышь для подбора следующей цепи.
-- Нажимаем среднюю кнопку.
-- Повторяем операцию еще раз.
-- И еще раз.
-- И еще раз.
-- И еще раз.
-- Нажимаем левую кнопку мыши, чтобы начать цепь.
-- Ведем мышь к целевой точке.
-- И снова нажимаем среднюю кнопку, чтобы согласиться с разумным режимом.
-- Нажимаем левую кнопку мыши, чтобы начать цепь.
-- Здесь разумный режим предлагает неудачный вариант.
-- Нажимаем левую кнопку мыши, чтобы добавить излом в нужной точке.

мыши указываем правильный излом.
