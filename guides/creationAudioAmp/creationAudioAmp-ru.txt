- Вставка цепей в схему
-- Включаем режим вставки цепей в схему.
-- При перемещении мыши "разумный режим" будет предлагать провести цепь между выводами
в зависимости от положения курсора мыши.
-- Добиваемся нужного положения и нажимаем среднюю кнопку мыши, чтобы
согласиться с разумным режимом.
-- Последовательно вводим цепи с помощью разумного режима нажатием средней кнопки
-- Можно начать вводить цепь вручную с помощью левой кнопки мыши, не обращая
внимания на разумный режим.
-- Разумный режим работает постоянно и после начала ручного ввода предлагает
завершение цепи. Нажатием средней кнопки соглашаемся с предложением.
-- Продолжаем ввод цепей с разумным режимом, пока его предложения нам подходят.
-- Снова вводим начало цепи и точку излома вручную, когда предложение разумного
режима нас не устраивает.
-- Когда завершение цепи становится нормальным - нажимаем
среднюю кнопку мыши, чтобы согласиться с "разумным режимом".
-- Вводим оставшиеся цепи комбинацией ручного и разумного режимов.

- Заключительное оформление схемы

-- Для идентификации компонентов, каждый из них содержит уникальный идентификатор
в пределах одной платы. SalixEDA может расставлять эти идентификаторы автоматически.
В меню Схема выбираем пункт Ренумерация.
-- При этом SalixEDA назначает компонентам идентификаторы в соответствии с правилами,
определенными в настройках. По умолчанию используются правила ГОСТ: сверху вниз и
слева направо.
-- Часто на схеме требуется нанести текстовые пометки. Для этого служит режим ввода текста.
-- Включаем режим ввода текста
-- Текст представляет собой одну строку символов. Для ввода такой строки наводим мышь
на место, где будет расположена эта строка и нажимаем левую кнопку мыши. Включается
ввод символов, а место ввода обозначается вертикальной черточкой.
-- Вводим символы с клавиатуры и завершаем ввод клавишей Enter или левой кнопкой мыши.
-- Повторяем ввод для других надписей. Левой кнопкой мыши отмечаем место, затем
вводим строку символов и нажимаем Enter для завершения ввода.
-- Чтобы завершить режим ввода текста нажимаем правую кнопку мыши. При этом возвращается
режим редактирования.

- Расстановка компонентов на плате
-- Включаем режим расстановки компонентов.
-- По умолчанию компоненты выравниваются по сетке. Устанавливаем более мелкую сетку.
-- В поле Шаг сетки вводим 0.625 или выбираем из списка предыдущих сеток 0.625х0.625.
-- Наводим курсор мыши на компонент и нажимаем левую кнопку мыши.
-- Перемещаем мышь, компонент перемещается вместе с мышью.
-- Для быстрой смены ориентации на 90 градусов по часовой стрелке нажимаем клавишу F2.
-- Чтобы поставить компонент в текущем положении нажимаем левую кнопку мыши.
-- Берем следующий компонент (X1), нажимаем левую кнопку мыши и перемещаем компонент.
-- Для поворота компонента используем F2.
-- Нажимаем левую кнопку для установки компонента.
-- Аналогичным способом расставляем остальные компоненты
-- Нажимаем правую кнопку для прекращения режима расстановки компонентов.

- Трассировка соединений
-- Включаем режим трассировки соединений.
-- По умолчанию узлы изломов трасс выравниваются по сетке. Устанавливаем более мелкую сетку.
-- При перемещении мыши система будет предлагать точку начала трассы.
Она показывает эту точку квадратиком.
-- Подводим мышь к первому контакту разъема X1 и нажимаем
левую кнопку мыши, чтобы начать трассу с предложенного места.
-- Разумный режим предлагает вариант завершения трассы. При этом трасса строится с
изломами 90 градусов.
-- Изменяем угол изломов на 45 градусов.
-- Перемещаем мышь таким образом, чтобы завершение трассы было таким, как нужно и
нажимаем среднюю кнопку мыши, чтобы принять предложение "разумного режима".
-- Аналогичным образом вводим оставшиеся трассы путем поиска начала трассы и
формирования нужного пути разумным режимом.
-- Иногда трасса не может быть проведена на текущем слое даже вручную. В этом
случае нужно перейти на нижний слой.
-- Нажимаем на кнопку, чтобы открыть список доступных слоев.
-- Выбираем bottom
-- При этом добавляется переходное отверстие и разумный режим работает уже на нижнем слое.
-- Нажимаем среднюю кнопку мыши, чтобы принять предложение "разумного режима".
-- Нажимаем правую кнопку мыши, чтобы завершить трассировку.
