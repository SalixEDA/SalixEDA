- ситуация с выводами
-- Современные микроконтроллеры имеют многофункциональные выводы.
-- Конкретная функция определяется конкретным проектом.
-- Есть проблема отображения этих функций.
-- Либо мы отображаем все возможные функции выводов. Тогда для каждого
вывода мы получаем внушительный список.
-- Либо мы не отображаем альтернативные функции совсем. Тогда на схеме
теряется информация о функциях.

- решение
-- Оригинальное решение было найдено для микроконтроллеров stm.
-- Мы на схеме для каждого вывода отображаем функцию из проекта.
-- Выделяем микроконтроллер.
-- Нажимаем правую кнопку мыши на нем.
-- Выбираем "Выбор параметров"
-- Нажимаем "Импорт выводов для stm"
-- Выбираем ioc файл
-- Параметры заполняются выводами из ioc-файла
-- Нажимем OK
-- Отключаем показ ссылок
-- Вместо ссылок видим назначенные выводы из ioc файла
-- Это уникальное решение позволяет синхронизировать назначение выводов
из проекта программы в схему.
